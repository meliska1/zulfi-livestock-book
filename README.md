# نظام حجز سوق مواشي محافظة الزلفي

تطبيق Next.js / Supabase / Vercel، بواجهة عربية RTL وحجز أسبوعي آمن.

## التثبيت
1. أنشئ مشروع Supabase جديدًا، وشغّل ملف `supabase/schema.sql` في SQL Editor.
2. انسخ `.env.example` إلى `.env.local` وأدخل `SUPABASE_URL` و`SUPABASE_SERVICE_ROLE_KEY` من إعدادات Supabase. لا تستخدم بادئة `NEXT_PUBLIC_` لهذه الأسرار.
3. عيّن `ADMIN_EMAIL`، وأنشئ تجزئة كلمة مرور باستخدام:
   `node -e "const c=require('crypto');const s=c.randomBytes(16).toString('hex');console.log(s+':'+c.scryptSync(process.argv[1],s,64).toString('hex'))" 'YOUR_STRONG_PASSWORD'`
   ضع النتيجة في `ADMIN_PASSWORD_HASH`، وعيّن `SESSION_SECRET` عشوائيًا باستخدام `openssl rand -hex 32`.
4. ضع الصورة الأصلية كما هي دون تعديل باسم `public/market-banner.png`. الصورة الأصلية مضافة إلى المشروع.
5. نفّذ `npm install` ثم `npm run dev` للاختبار محليًا.
6. ارفع المشروع إلى GitHub ثم أنشئ مشروعًا في Vercel باسم `zulfi-livestock-booking`، وأضف متغيرات البيئة نفسها في Vercel ثم انشر.
7. بعد النشر، افتح الرابط من هاتفين مختلفين وجرب حجز الرقم نفسه في اللحظة نفسها، وتحقق من نجاح طلب واحد فقط. اختبر أيضًا رقم جوال مكرر، فتح/إغلاق الوقت، لوحة الإدارة، الإلغاء، التصدير والأرشيف. استخدم مشروع اختبار مستقل لتجنب التأثير في حجوزات حقيقية.
8. بعد الحصول على رابط الإنتاج الفعلي، أنشئ QR لذلك الرابط فقط.

## ملاحظات أمنية وتشغيلية
- قيود الفهرس الفريد في PostgreSQL تمنع حجز الرقم أو الجوال مرتين في الأسبوع حتى عند التزامن. عملية الحجز في دالة PostgreSQL ذرية.
- لا توجد سياسات قراءة عامة للبيانات الشخصية؛ يمر كل الوصول عبر API خادمي.
- الإعداد اليدوي `open` يتجاوز نافذة الوقت المحددة حتى يعاد إلى `auto`؛ يظل الأسبوع مرتبطًا بأقرب اثنين. عند انتهاء الاثنين ينتقل الأسبوع القادم تلقائيًا.
- التحديث كل 4 ثوانٍ (near-real-time polling)، وليس بثًا لحظيًا حرفيًا. قيود قاعدة البيانات تحمي من السباق حتى خلال فترة التحديث.
- قبل الإنتاج العام، يوصى بإضافة Rate Limiting وCAPTCHA وتسجيل تدقيق للإدارة، ومراجعة الامتثال لخصوصية البيانات.
- لا توجد حجوزات تجريبية ضمن المشروع.

## تحديث صورة اللمبات
الصورة المطلوبة هي لوحة اللمبات الأصلية التي تحمل اسم سوق مواشي محافظة الزلفي. احفظ النسخة الأصلية دون قص أو تعديل في `public/market-banner.png`، وستظهر تلقائيًا في أعلى الصفحة. **الصورة الأصلية مضافة بالفعل دون تعديل.**

## كيف تصبحين المسؤولة؟
اختاري بريدك الإداري في `ADMIN_EMAIL` وكلمة مرور قوية، ثم خزّني تجزئتها في `ADMIN_PASSWORD_HASH` كما في الخطوات أعلاه. بعد النشر افتحي `/admin` في رابط موقعك وسجّلي الدخول. لا تضعي كلمة المرور أو مفتاح Supabase في مستودع GitHub أو داخل واجهة الموقع.
